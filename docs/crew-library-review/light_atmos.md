## 정하지 못한 것 / 제안
- crew_knowledge.json: space 단계의 lighting prefer 에 `practical_light` 가 있어 실내 항목을 그쪽으로 옮겼다. landscape 단계에는 atmosphere 의 prefer 가 없으니 `mist_fog`, `particles`, `water_effect` 를 넣는 것을 제안.
- crew_intent.json 에 넣을 만한 말: 렘브란트 조명, 버터플라이 조명, 스플릿 라이트, 클램셸, 골든아워, 블루아워, 여우비, 윤슬, 상고대, 포장마차, 한옥.

- 'neon sign' 계열은 조명·대기 칸 모두 'neon tubes / neon light' 로 통일했다. 다른 칸(props, location_set)에도 같은 말이 남아 있을 수 있다.
