## 문제 유형별 (전 → 후)
1. 글자·간판·상표 (약 14): `neon sign palette` → `neon light palette`, `subway map` → `transit line color`, `gold lettering` → `gilt edges`, 포스터 → 구성주의 인쇄물·스위스 스타일 그래픽, 테크니컬러·로모 → 옛 총천연색·토이카메라
2. 대상 이름 태그가 요청에서 항목을 빼 버림 (약 90): `ko`·태그에 향수·맥주·커피·시계·카페·거실 등이 있으면 그 제품 요청에서 오히려 걸러짐 → 색·소재 이름으로 바꿈 (예: 향수병 팔레트 → 호박색 유리병 골드 팔레트)
3. 사람 낱말 `baby`·`hair` 때문에 사람 없는 요청에서 빠짐 (약 20): `baby blue` → `powder blue`
4. 인물 외모 항목 15개 삭제: 머리색·눈색·피부색 팔레트는 색 팔레트가 아니라 외모 지정 (고정관념·외모 평가 위험)
5. 겹침·모순 삭제 35개: 밝은 검정, 파스텔 남색 같은 모순 변형, 같은 네 색 반복(부활절 파스텔, 키즈룸 원색, 장난감 블록 등)
6. 조화 이름 정확성: 짙은·옅은 보색·삼각·사각 변형을 모호한 `dark lemon yellow` 대신 실제 색 이름(olive gold, aubergine 등)으로, 분열 보색은 분할 보색으로, 사각 배색은 정사각 4색임을 명시
7. 문화 정확성: 금단청(비단 문양), 모로단청(끝에만 문양), 사하라 인디고, 호주 원주민 점화는 의례 양식 모방을 피해 대지 안료색으로, 오방색 확인어(obangsaek)가 en 에 들어가게
8. fits 정리: 제작진 분야(제품·공간·풍경)에서 쓰이게 조정 (예: 도시 밤 → landscape·architecture)
