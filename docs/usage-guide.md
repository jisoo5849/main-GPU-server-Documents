# 메인 서버 GPU 사용 방법

메인 서버의 GPU 로 ComfyUI 를 쓰는 방법입니다.
사무실 안에서 쓰는 방법과 사무실 밖(외부 네트워크)에서 쓰는 방법, 두 가지가 있습니다.
어느 쪽이든 실행한 작업은 같은 GPU 대기열에 순서대로 들어가 메인 GPU 에서 처리됩니다.

## 1. 사내에서 사용하기

- ComfyUI 접속 주소: `http://192.168.10.29/`
  - 예: 로그인하면 내 ComfyUI 가 바로 열립니다.
- 관리자 페이지: `http://192.168.10.29/admin`
  - 예: 관리자 계정으로 로그인해야 열립니다. 관리자 계정의 아이디와 비밀번호는 관리자(지수)에게 문의합니다.
- 작업자 계정은 관리자가 서버 PC 에서 만들어 줍니다.

### 새 작업자 계정 만들기 (관리자, 서버 PC 에서)

```bash
cd /opt/mgs-src && sudo bash install/add-user.sh minji "김민지"
```

- `minji` 는 로그인 아이디이고, `"김민지"` 는 사용자 이름입니다.
- 비밀번호를 두 번 묻습니다.
  - 예: 8자 이상이어야 하고, 입력할 때 글자가 안 보이는 것이 정상입니다.
- 관리자 권한을 줄 사람은 명령 끝에 `--admin` 을 붙입니다.
  - 예: `sudo bash install/add-user.sh minji "김민지" --admin`

## 2. 외부 네트워크에서 사용하기 (VPN)

사무실 밖에서는 Tailscale VPN 에 들어온 뒤에만 메인 서버에 접속할 수 있습니다.
VPN 은 사무실 밖에서 메인 서버로 들어오는 보안 통로이고, 인터넷에는 서버 포트를 열어 두지 않습니다.

### 작업자가 할 일

1. 관리자(지수)에게 Tailscale 초대 메일 발송을 요청합니다.
   - 예: 받을 메일 주소를 관리자에게 알려 줍니다.
2. 내 PC 에 Tailscale 을 설치합니다.
   - 예: https://tailscale.com/download 에서 받습니다.
3. 초대 메일의 링크로 로그인하고, 관리자 승인을 받습니다.
   - 예: Google, GitHub 등 가지고 있는 계정으로 로그인할 수 있습니다.
4. Tailscale 아이콘이 `Connected` 상태인지 확인합니다.
5. ComfyUI 로그인 계정을 관리자에게 요청합니다.
   - 예: Tailscale 로그인은 메인 서버로 가는 길만 열어 줍니다. ComfyUI 계정은 서버 PC 에서 따로 만들어야 합니다.
6. 브라우저에서 `http://100.112.253.4/` 로 접속해 ComfyUI 계정으로 로그인합니다.
   - 예: 사무실 주소(`192.168.10.29`)는 밖에서 열리지 않으니 이 주소로 북마크를 따로 만듭니다.

### 알아 둘 점

- 결과 폴더(`\\...\results`)는 기본으로 막혀 있습니다.
  - 예: 결과는 ComfyUI 화면에서 저장해서 받습니다.
- 채팅 화면(Open WebUI, 8090)은 밖에서 열리지 않습니다.
- 메인 서버가 꺼져 있거나 재부팅 중이면 사용할 수 없습니다.
  - 예: 메인이 다시 켜지면 VPN 은 자동으로 다시 연결됩니다.
- 노트북을 잃어버리면 바로 관리자에게 알립니다.

### 관리자가 할 일

- 작업자 초대와 기기 승인은 Tailscale 관리 콘솔(https://login.tailscale.com/admin)에서 합니다.
- 메인 서버 설치와 보안 판단은 [vpn-tailscale.md](vpn-tailscale.md), [handover-2026-10-30-vpn.md](handover-2026-10-30-vpn.md)에 있습니다.
